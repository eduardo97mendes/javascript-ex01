# 📚 Sobre a atividade

Nesta atividade você irá desenvolver e personalizar uma **Landing Page de uma hamburgueria**, utilizando:

- HTML
- CSS
- JavaScript

O projeto foi desenvolvido para que você possa **aprender praticando**.

Você receberá um código-base já estruturado e deverá completar as partes indicadas nos arquivos.

⚠️ **Você não deverá simplesmente copiar o código e entregar.**

A atividade possui explicações e exercícios dentro dos próprios arquivos.

Você deverá:

> **Ler → Entender → Completar → Testar → Personalizar → Publicar**

---

# 🎯 Objetivo

O objetivo desta atividade é praticar os conhecimentos de **Programação Web**, trabalhando HTML, CSS e JavaScript dentro de um projeto real.

Ao final da atividade você deverá ser capaz de:

- compreender a estrutura de uma página HTML;
- utilizar elementos HTML;
- aplicar estilos utilizando CSS;
- utilizar variáveis JavaScript;
- trabalhar com `var`, `let` e `const`;
- compreender tipos de dados;
- criar funções;
- utilizar parâmetros;
- utilizar condições;
- manipular elementos HTML através do JavaScript;
- responder a eventos;
- criar pequenas funcionalidades;
- personalizar uma página;
- organizar um projeto;
- publicar um projeto no GitHub.
